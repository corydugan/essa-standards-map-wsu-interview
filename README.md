# Exercise Physiology Practice 2030

A single-page map of what Exercise and Sports Science Australia (ESSA) requires of an
exercise physiologist, opened one level deeper than a mind map goes.

**Live page: https://corydugan.github.io/essa-standards-map-wsu-interview/**

Every node carries the standard element or code clause behind it, in the regulator's own
words, and names the document it came from. Where the map's label is not a phrase the
standards actually use, the page says so rather than filling the gap with something that
sounds right.

49 topics. The page searches across all of them, and opens every hit.

## Two things the page is careful about

- **Artificial intelligence** is governed by the Code of Professional Conduct, clauses
  2.9.6 and 2.9.7, and by worked examples in the User Guide and the AES Support Guide. The
  Professional Standards version 4.0 and the Digital Practice Standards address digital
  practice more broadly. The page names the instrument each requirement comes from.
- **The Practicum Standards file is named for 2023 and is version 1.3, dated July 2026.**
  The version and date are on the cover page, not in the filename.

## Sources

Eighteen source documents, linked at the foot of the page, each one verified as resolving
to the issuing body's own page. Every quotation was read out of the document named beside
it.

## Technical

One HTML file, no build step, no dependencies, no tracking. Fonts load from Google Fonts;
everything else is inline. Works at phone width, and in light and dark.
