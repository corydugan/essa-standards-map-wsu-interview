# Exercise Physiology Practice 2030

A single-page map of what Exercise and Sports Science Australia (ESSA) requires of an
exercise physiologist, opened one level deeper than a mind map goes.

**Live page: https://corydugan.github.io/essa-standards-map-wsu-interview/**

Every node carries the standard element or code clause behind it, in the regulator's own
words, and names the document it came from. Where the map's label is not a phrase the
standards actually use, the page says so rather than filling the gap with something that
sounds right.

## The honest bits

Five nodes are flagged in amber because the phrase in common professional use does not
appear in the standards. Two of those are worth knowing about before you teach from them:

- **Artificial intelligence** appears nowhere in the Digital Practice Standards or in the
  Professional Standards version 4.0. It is governed by the Code of Professional Conduct,
  clauses 2.9.6 and 2.9.7, and by examples in the User Guide.
- There is **no prohibitive list** of interventions that must not be automated. What exists
  is a requirement for human review of reports generated by artificial intelligence, and a
  clause governing delegation.
